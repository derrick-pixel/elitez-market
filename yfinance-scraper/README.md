# yfinance-scraper

Migrated into `elitez-market` from the standalone repo `derrick-pixel/yfinance-scraper` on 2026-07-23.

This folder contains the Yahoo Finance ticker scraper (`scraper.py`, `run.py`,
`config.py`, `tickers.py`) used to pull market data feeding this analytics product.

Note: the scraped output `data/` directory was intentionally excluded from this
migration (reproducible via `scraper.py`, and was already excluded from the
original repo backup).

The original standalone repository has been archived on GitHub; this is now the
canonical location for this code.
